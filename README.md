# Modern Baby Type

Игра для детей, которая учит печатать вслепую. Зайчик бежит по строке текста и
объедает буквы, а ёж ползёт следом. Ошибка — это красная буква вместо нужной и
откат назад; догнал ёж — уровень проигран.

Версия **0.0.5**. Это ранняя сборка: правила и тексты ещё меняются.

## Как устроена игра

Печатать нужно **чёрные** буквы. Серые пролетают сами — так ребёнок привыкает
двигать пальцы не глядя. Сложность растёт постепенно: на старте доступны только
пробел, «а» и «о», а каждая новая буква алфавита открывается после трёх побед
подряд. Всего в цепочке 56 знаков, от букв до цифр и знаков препинания.

Скорость ёжа подстраивается под игрока: цель считается в символах в секунду
(не в пикселях, поэтому от ширины окна ничего не зависит) и растёт с уровнем,
опираясь на скользящее среднее темпа игрока. Слабый игрок получает снижение на
четверть, сильный — прибавку. Победа и поражение сдвигают скорость ступенчато.

## Что умеет

- **Профили игроков.** Свой прогресс у каждого ребёнка: открытые буквы, серия
  побед, темп, точность. При запуске игра предлагает последнего игрока.
- **Гостевой режим.** Esc в меню — играть без профиля и ничего не записывать.
  Годится для гостей и для «просто поиграть».
- **Переключатель «все клавиши».** Клавиша A в меню открывает профиль целиком,
  независимо от прогресса, — удобно, когда буквы нужны все сразу (например для
  показа ребёнку или для проверки набора). В релизной сборке переключатель
  виден всегда, но буквы по умолчанию всё равно идут от прогресса.
- **Ошибки без наказания вслепую.** Опечатка не стирает букву, а заменяет её
  красной: ребёнок видит, что нажал не то. Backspace убирает ошибку и отводит
  назад.
- **Случайные куски текстов.** Игра берёт фрагменты из файлов в `game/texts/`,
  поэтому повторов не бывает.
- **Статистика.** CPM, точность, серия побед — видно в HUD и по итогам уровня.

## Управление

### В игре

| Клавиша | Действие |
|---|---|
| **А, О, активные буквы** | Набор текста (чёрные символы) |
| **Backspace** | Убрать ошибку справа или отступить назад |
| **Enter** | Следующий уровень после победы или поражения |
| **F2** | Меню игроков: сменить профиль или выйти из профиля |
| **F3** | Отладочная строка сверху |
| **F11** | Полный экран |
| **Alt+Enter** | Полный экран (дубль F11) |
| **Esc** | Выйти из полного экрана, а из окна — закрыть игру |

#### Тач и мышь (в игре)

Тап по кнопке «Дальше» — то же, что Enter. Тап по ⌨ справа вверху —
вызвать системную клавиатуру. Тап по ≡ — меню игроков (то же, что F2).

### В меню игроков

| Клавиша | Действие |
|---|---|
| **↑ ↓** | Выбор в списке (с заворачиванием) |
| **Enter** | Играть под выбранным или создать введённое имя |
| **Tab** | Поле ввода нового имени (при первом запуске оно уже открыто — просто печатайте) |
| **Backspace** | Стереть символ в поле ввода |
| **A** | Переключатель «все клавиши» для выбранного профиля (то же — галочка «Все клавиши» под списком) |
| **Delete** | Удалить выбранный профиль |
| **Esc** | Играть без профиля (гостевой режим) |
| **F2** | Вернуться в игру тем же игроком, кем открыто меню |

#### Тач и мышь (в меню)

Тап по строке — сразу играть этим игроком. Тап по полю — ввести имя.
Кнопки «Играть» и «Без профиля» дублируют Enter и Esc, кнопка ⌨
справа вверху вызывает системную клавиатуру.

Пока открыто меню, игра стоит на паузе — буквы, которые игрок нажимает в этот
момент, в игру не уходят.

### Ночной режим

По умолчанию — как у системы (на телефоне — её тёмная тема). Кнопка
«Ночь»/«День» в меню переключает вручную и запоминает выбор. Ночью небо
тёмное с луной и звёздами, тексты светлые, зайчик и ёж притемнены.

## Скачать и запустить

Сборки лежат в [релизах](https://github.com/NikitaShubin/ModernBabyType/releases)
(тег `v*`). Тесты в GitHub Actions прогоняются автоматически, бинарники
прикладываются к релизу оттуда.

### Windows

`ModernBabyType.exe` — один файл, установка не нужна. Игра сразу
во весь экран; переключить — F11.

### Linux

```bash
chmod +x ModernBabyType.x86_64
./ModernBabyType.x86_64
```

### macOS

`ModernBabyType.zip` — обычный zip без установки, распакуйте и запустите
`ModernBabyType.app`. Сборка не подписана (подпись и notarization
недоступны вне macOS), поэтому Gatekeeper её блокирует — это ожидаемо для
любой бесподписной игры. Дальше один из двух путей:

- **Правый клик по `ModernBabyType.app` → «Открыть» → «Открыть».** Этот путь
  переживает перезагрузку: macOS запомнит, что приложение проверено.
- Либо один раз в терминале, после распаковки:

  ```bash
  xattr -dr com.apple.quarantine ModernBabyType.app
  open ModernBabyType.app
  ```

Сборка universal (Intel и Apple Silicon), системные требования — macOS 10.13 и
новее.

### Android

`ModernBabyType.apk` — обычный APK, Android 5.0 и новее, только 64-битные телефоны
(ARM64). Поставить можно перебросив файл на телефон и разрешив установку из
неизвестных источников, либо через `adb install`.

Основной режим — портретный: телефон держится вертикально, системная
клавиатура появляется сама (в поле имени — для ввода, в партии — для букв),
а игра сдвигается вверх, чтобы клавиатура ничего не закрывала. Кнопка ⌨
справа вверху вызывает клавиатуру вручную — например, если её смахнули
кнопкой «назад». Альбомный режим — для внешней (bluetooth) клавиатуры:
системную там тоже можно вызвать кнопкой ⌨. Тапы работают везде: строки
и кнопки в меню, кнопка «Дальше» после уровня.

**Про Google Play.** В релизе лежит APK, подписанный отладочным ключом, который
генерируется на лету в образе сборки. Play его не примет: для публикации нужна
своя подпись, а она не может лежать в открытом репозитории. См. «Сборка из
исходников».

### Почему нет версии в браузере

Игра целиком про клавиатуру: игрок набирает текст, ловит опечатки, жмёт
F2/F3/F11. В браузере всё это упирается в то, что вкладка должна быть в фокусе,
а раскладку и события `keydown` браузеры отдают по-своему — на некоторых
комбинациях игра просто не сможет узнать, какую букву нажали. Плюс на Android
и iOS там не настольная клавиатура. Поэтому платформы только десктопные и
Android.

## Как играть

1. Выберите профиль, введите имя (при первом запуске поле уже ждёт ввода) или нажмите **Esc** для гостевого режима.
2. Печатайте **чёрные** буквы. Серые пропускаются сами.
3. Не спешите: опечатка — красная буква вместо нужной и откат назад.
4. **Backspace** убирает ошибку справа от зайчика.
5. Убегайте от ежа: он идёт по вашему следу. Поймал — уровень проигран.
6. Три победы подряд — открылась новая буква.

## Профили игроков

Профили лежат в файле `user://modern_baby_type.cfg` рядом с другими данными
игры (в Windows — `%APPDATA%\Godot\app_userdata\ModernBabyType\`, в Linux —
`~/.local/share/godot/app_userdata/ModernBabyType/`). Файл текстовый, его можно
смотреть и править руками.

Если играете в гостевом режиме, прогресс не записывается. При запуске игра
сразу начинает игру под последним профилем, если он есть, а меню игроков
открывается **F2**. Профилей ещё ни одного — меню показывается само; после
гостевого сеанса — тоже, потому что гостя игра запомнить не может.

## Свои тексты

Кладите `.txt` в `game/texts/` — игра сама подхватит все файлы оттуда и будет
брать случайные куски. Имена файлов значения не имеют. Тексты лучше брать
простые, без сложной пунктуации: для начальных уровней это важно.

Сейчас в репозитории пять текстов: учебные (`training.txt`), сказки
(`tales.txt`), басни Крылова (`krylov.txt`), стихи Пушкина (`pushkin.txt`)
и демонстрационный (`demo.txt`).

## Сборка из исходников

Всё, что нужно для сборки, лежит в репозитории: движок и Android SDK ставятся
в контейнер, а не в систему.

```bash
tools/docker/build-game.sh --all
```

Скрипт соберёт образ из `tools/docker/Dockerfile`, прогонит тесты и положит
в `game/dist/` четыре файла: `.exe`, `.x86_64`, `.zip` и `.apk`.

Отдельные режимы:

```bash
tools/docker/build-game.sh --test-only          # только тесты
tools/docker/build-game.sh --preset Linux        # одна платформа
tools/docker/build-game.sh --preset Android      # одна платформа
```

Образ — один и тот же, что и в CI: правила сборки не должны расходиться между
машиной разработчика и GitHub Actions.

### Через редактор

Если Godot 4.3+ уже установлен, достаточно открыть папку `game/` в редакторе и
нажать F5. Экспорт — `Project → Export` по готовым пресетам из
`game/export_presets.cfg`. Пресеты в репозитории — источник правды: пути к
подписывающим утилитам в них не зашиты, их подставляет контейнер.

Своя подпись для Android: создайте ключ (`keytool -genkeypair`) и укажите его
в пресете либо в переменных `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`,
`..._USER`, `..._PASSWORD`.

### Тесты

```bash
tools/docker/build-game.sh --test-only
```

Три набора, все обязательны:

- `LOGIC_TEST` — ввод, опечатки, адаптивная сложность, детерминированно.
- `PROFILES_TEST` — меню игроков, создание, вход, удаление, «все клавиши».
- `CHASE_TEST` — инвариант погони: живой цикл со случайным вводом, на каждом
  кадре проверяется, что ёж не оказался впереди зайчика.

```text
└── LICENSE
```
