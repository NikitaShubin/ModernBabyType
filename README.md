# Modern Baby Type

Простая игра для детей, обучающая быстрому набору текста на клавиатуре.

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![Pygame](https://img.shields.io/badge/pygame-2.0+-green.svg)
![License](https://img.shields.io/badge/license-MIT-orange.svg)

## Описание

Modern Baby Type — это образовательная игра, помогающая детям освоить слепую печать в
игровой форме. Игрок управляет героем (синий квадрат), который движется по тексту,
набирая символы и убегая от догоняющего врага (красный круг).

Игра построена на принципе постепенного усложнения: начиная с двух простых букв («а» и
«о») и пробела, ребенок постепенно осваивает весь алфавит, причем новые буквы
открываются только после стабильного прохождения предыдущих уровней.

## Особенности

- **Система пользователей**: Создавайте профили для разных детей, сохраняйте прогресс
  автоматически. При запуске игра войдет под последним активным пользователем.
- **Гостевой режим**: Можно играть без сохранения прогресса — идеально для гостей или
  тренировки.
- **Адаптивная сложность**: Начинайте с простых букв «а» и «о», постепенно открывайте
  новые символы по мере успехов
- **Реалистичная механика ошибок**: Неверно нажатая клавиша создает красную букву перед
  игроком и отбрасывает его назад. Ошибки нужно исправлять клавишей Backspace
- **Случайные тексты**: Игра берет случайные фрагменты из текстовых файлов в папке
  `texts/`, что делает каждую попытку уникальной
- **Статистика прогресса**: Отслеживание скорости печати (CPM), точности и серии побед

## Управление

### В игре

| Клавиша                    | Действие                                          |
|----------------------------|---------------------------------------------------|
| **А, О, [активные буквы]** | Набор текста (черные символы)                     |
| **Backspace**              | Удаление ошибки справа от игрока или отступ назад |
| **F11**                    | Переключение полноэкранного режима                |
| **Enter**                  | Продолжить после победы/поражения                 |
| **F2**                     | Сменить игрока / выйти в меню выбора              |
| **Escape**                 | Выход из игры                                     |

### В меню выбора игрока

| Клавиша   | Действие                               |
|-----------|----------------------------------------|
| **↑ / ↓** | Выбор пользователя из списка           |
| **Enter** | Войти как выбранный пользователь       |
| **Tab**   | Перейти к полю ввода нового имени      |
| **Del**   | Удалить выбранного пользователя        |
| **Esc**   | Играть без сохранения (гостевой режим) |
| **ЛКМ**   | Клик по пользователю для входа         |

## Как играть

1. **При запуске** выберите игрока или нажмите Esc для гостевого режима.
1. **Набирайте активные символы** (черные символы и пробелы). Серые символы
   пропускаются автоматически.
1. **Не допускайте ошибок** — неверная буква создаст красный символ и отбросит игрока
   назад.
1. **Исправляйте ошибки** — нажмите Backspace, чтобы удалить красную букву справа от
   игрока.
1. **Убегайте от врага** — красный круг догоняет вас сзади. Если он догонит — игра
   окончена.
1. **Прокачивайтесь** — после 3 побед подряд открывается новая буква алфавита.

## Система пользователей

**Важно**: Если вы играете в гостевом режиме (нажали Esc в меню) и потом нажмете **F2**,
игра вернется в меню выбора, а при следующем запуске снова покажет меню (так как
последний сеанс был без сохранения).

Чтобы сохранить прогресс:

1. Выйдите в меню по **F2**
1. Создайте пользователя или выберите существующего
1. Продолжайте играть — прогресс будет сохраняться автоматически

## Добавление собственных текстов

Положите `.txt` файлы с рассказами или текстами в папку `texts/`. Игра будет случайным
образом выбирать фрагменты из этих файлов. Рекомендуется использовать тексты без
сложных символов для начальных уровней.

Структура проекта:

```text
ModernBabyType/
├── main.py
├── progress.json
├── texts/*.txt
├── LICENSE
└── README.md
```

## Настройка

Основные параметры можно изменить в начале файла `main.py`:

```python
KEY_PROGRESSION       # Последовательность октрываемых знаков
INITIAL_ACTIVE_COUNT  # Количество активных знаков на старте (3 = пробел, а, о)
WINS_TO_LEVEL_UP      # Необходимое число побед подряд для открытия новой буквы
BASE_ENEMY_SPEED      # Базовая скорость врага
MAX_USERNAME_LENGTH   # Максимальная длина имени пользователя (15 символов)
```
