# Спрайты

Оба героя нарисованы нейросетью через бесплатный сервис
`image.pollinations.ai` (без ключа), сентябрь–октябрь 2026. В
репозитории лежат только те спрайты, которые игра использует прямо
сейчас. Промпты, сиды и вся обработка — текстом ниже; исходных JPEG в
репозитории нет.

| файл | что это |
|------|---------|
| `hero.png` | заяц-герой, 139×160, спрайт целиком (без полотна) |
| `hedge.png` | ёж-колобок, содержимое 147×140 в полотне 160×160, низ на y=150 |

## Как получить

Перерисовывать картинки смысла нет: спрайты в `assets/` — это
окончательные файлы, игра использует именно их. Ниже — рецепт на
случай, если придётся делать заново (другой зверь, другой сервис,
потерянный файл).

Порядок: **шаг 1** — забрать JPEG у сервиса, **шаг 2** — снять фон и
вписать в полотно скриптом.

### Шаг 1. Забрать картинку у сервиса

Ключ не нужен. Параметр `model` сервис игнорирует, внутри одна модель.
Качай куда угодно, только не в репозиторий: `/tmp` — хороший выбор.

```bash
# заяц
curl -sL --max-time 150 \
  "https://image.pollinations.ai/prompt/soft%203d%20cartoon%20game%20sprite%20round%20golden%20kolobok%20bun%20smooth%20top%20no%20ears%20no%20limbs%20tiny%20feet%20big%20dark%20friendly%20eyes%20looking%20right%20small%20smile%20blush%20cheeks%20thick%20outlines%20solid%20pure%20white%20background%20centered?width=512&height=512&nologo=true&seed=1234" \
  -o /tmp/spritesrc/hero3.jpg

# ёж
curl -sL --max-time 150 \
  "https://image.pollinations.ai/prompt/soft%203d%20cartoon%20game%20sprite%20cute%20round%20hedgehog%20curled%20into%20a%20tight%20ball%20NO%20ears%20spherical%20body%20fully%20covered%20with%20short%20dark%20brown%20spines%20all%20over%20small%20cream%20round%20face%20patch%20on%20front%20with%20sly%20half-open%20eyes%20looking%20RIGHT%20tiny%20nose%20thick%20clean%20outlines%20crisp%20sharp%20plain%20light%20background%20centered%20character%20only%20no%20legs%20no%20arms%20no%20tail?width=512&height=512&nologo=true&seed=888" \
  -o /tmp/spritesrc/hedge3.jpg
```

Сервис бесплатный и капризный: при лимите отдаёт пустой ответ — тогда
`sleep 20..30` и повторять тот же запрос. Приходят JPEG 512×512, в
которых фон — серый градиент с тенью, а снизу водяная плашка (38 px),
которую всё равно приходится срезать, даже с `nologo=true`.

### Шаг 2. Снять фон и вписать в полотно

Скрипт ниже — ровно тот, которым получены нынешние спрайты. Нужен
`pillow` и `numpy`; для зайца дополнительно `rembg`
(`pip install rembg onnxruntime` — в rembg 2.0.85 сессия по умолчанию
`bria-rmbg`, её веса 1.02 ГБ скачиваются сами в `~/.rembg/models/`).

Порядок работы такой же, как в игре:

1. срезать плашку — 38 px снизу;
2. снять фон:
   - **заяц** — `rembg`;
   - **ёж** — флуд-заливкой от границ кадра: фон везде касается края, а
     мех и морда замкнуты иглами, и заливка их не достаёт. `rembg` у ежа
     иглы съедал — поэтому у него своя ветка;
3. обрезать по содержимому;
4. ежа: срезать низ с двумя мелкими ножками (генератор пририсовал их
   вопреки `no legs`), отзеркалить (в исходнике морда слева, а в игре
   ёж идёт вправо, по ходу погони), вписать в полотно 160×160 — ширина
   до 150, низ на y=150;
5. заяц: спрайт целиком, ресайз LANCZOS до высоты 160 px, без полотна.

```python
"""Спрайты из исходных JPEG pollinations: hero3.jpg -> hero.png, hedge3.jpg -> hedge.png.

Запуск:  .venv/bin/python make_sprites.py /tmp/spritesrc [каталог для .png]
Нужны pillow и numpy; для зайца ещё rembg (см. выше).
"""

import sys
from collections import deque
from pathlib import Path

import numpy as np
from PIL import Image, ImageFilter

SRC = Path(sys.argv[1] if len(sys.argv) > 1 else "/tmp/spritesrc")
OUT = Path(sys.argv[2] if len(sys.argv) > 2 else "game/assets")

BAND = 38        # нижняя полоса с водяным знаком pollinations
BOTTOM = 150     # низ спрайта внутри полотна 160x160
HEDGE_FEET = 442 # у hedge3.jpg ниже этой строки только две ножки


def plate_off(im):
    """Срезать водяную плашку снизу."""
    w, h = im.size
    return im.crop((0, 0, w, max(1, h - BAND)))


def flood_alpha(im):
    """Альфа по флуд-заливке от границ кадра."""
    a = np.asarray(im).astype(int)
    mx, mn = a.max(axis=2), a.min(axis=2)
    bg_like = ((mx - mn) < 50) & (mx > 60)
    h, w = bg_like.shape
    keep = np.zeros((h, w), dtype=bool)
    dq = deque()

    def push(y, x):
        if bg_like[y, x] and not keep[y, x]:
            keep[y, x] = True
            dq.append((y, x))

    for x in range(w):
        for y in (0, h - 1):
            push(y, x)
    for y in range(h):
        for x in (0, w - 1):
            push(y, x)
    while dq:
        y, x = dq.popleft()
        for yy in range(max(0, y - 1), min(h, y + 2)):
            for xx in range(max(0, x - 1), min(w, x + 2)):
                push(yy, xx)

    alpha = np.where(keep, 0, 255).astype(np.uint8)
    return Image.fromarray(alpha, "L").filter(ImageFilter.GaussianBlur(1))


def flood_cutout(im):
    rgba = im.convert("RGBA")
    rgba.putalpha(flood_alpha(im))
    return rgba


def hero_cutout(im):
    """Заяц: rembg. Без него (флуд-заливка) выйдет похоже, но не то же,
    поэтому падаем с внятным сообщением, а не собираем не то."""
    try:
        from rembg import remove
    except ImportError:
        raise SystemExit(
            "заяцу нужен rembg: pip install rembg onnxruntime "
            "(веса bria-rmbg 1.02 ГБ скачаются сами)"
        )
    return remove(im)


def into_canvas(im):
    """Вписать в полотно 160x160: ширина до 150, низ на y=150."""
    canvas = Image.new("RGBA", (160, 160), (0, 0, 0, 0))
    scale = min(150 / im.width, 140 / im.height)
    r = im.resize(
        (max(1, int(im.width * scale)), max(1, int(im.height * scale))),
        Image.LANCZOS,
    )
    canvas.paste(r, ((160 - r.width) // 2, BOTTOM - r.height), r)
    return canvas


def build(src, cutout):
    """Снять фон. Обрезку по содержимому делает вызывающий — у ежа она
    должна идти ПОСЛЕ среза ножек, иначе меняется геометрия."""
    im = plate_off(Image.open(src).convert("RGB"))
    out = cutout(im)
    if out.getbbox() is None:
        raise SystemExit(f"{src.name}: пусто после вырезания фона")
    return out


# Заяц: спрайт целиком, без полотна, высота ровно 160.
hero = build(SRC / "hero3.jpg", hero_cutout)
hero = hero.crop(hero.getbbox())
scale = 160 / hero.height
hero = hero.resize((int(hero.width * scale), 160), Image.LANCZOS)
hero.save(OUT / "hero.png")

# Ёж: сначала срезать ножки, потом обрезка по содержимому, зеркало, полотно.
hedge = build(SRC / "hedge3.jpg", flood_cutout)
hedge = hedge.crop((0, 0, hedge.width, HEDGE_FEET))  # ножки — за кадром
hedge = hedge.crop(hedge.getbbox())
hedge = hedge.transpose(Image.FLIP_LEFT_RIGHT)       # мордой вправо, к зайцу
into_canvas(hedge).save(OUT / "hedge.png")

print("готово:", OUT / "hero.png", hero.size, "и", OUT / "hedge.png", into_canvas(hedge).size)
```

репозитории: с `rembg` оба спрайта собирались **байт-в-байт**, без него
— ёж байт-в-байт, а заяц выходил 147×160 вместо 139×160 (флуд-заливка
оставляет кусок тени). Сами JPEG 04.10.2026 удалены из репозитория по
решению автора: рецепт остался текстом, эталон — сами `hero.png` и
`hedge.png`.

## Почему именно так: что пробовали и отбросили

- **Покадровая генерация (лист бега, видео) — не работает.** Сгенерированный
  лист из 4 кадров (`seed=99`, 1024×256) режется на кадры, но между ними
  плывут глаза, полоски и усы, а сами кадры выходят смазанными — из них
  получается клякса, а не зверь. Проверено и на спиральных прогонах с
  ключом: видеомодели pollinations (`seedance`, `wan`, `nova-reel`)
  требуют API-ключ, а на бесплатном тарифе Pollen не хватает даже на
  один шестисекундный клип.
- **Один спрайт + анимация трансформацией.** На все фазы один и тот же
  пиксель: связность по построению, моргать нечему. У ежа походки нет
  вовсе — это шар, он катится.
- **Лис, мышь, кошка — удалены.** Сгенерированные варианты: бегущий лист
  (`seed=99`) и стоящий лис (`seed=111`), покадровые наборы мыши и кошки.
  Всё это плавало между кадрами, а у стоящего лиса вдобавок длинные
  неподвижные лапы выглядели неестественно, и пыль из-под хвоста
  читалась как пердёж.
- **Ёж: три попытки, первые две — мимо.** `seed=555` — «спящий моти:
  глаз нет, иголок нет, весь кремовый как заяц». `seed=777` — «морда
  отличная, но это кот: уши, меха вместо игл». Третий (`seed=888`) —
  настоящий ёж, и тёмное тело дало контраст с кремовым зайцем.
- **Локальная генерация (Stable Diffusion, AnimateDiff) — отброшена.** Модель
  SD1.5 на CPU ставит зверя на дыбы, если в промпте есть слова
  «cute/adorable/chibi»: рисует персонажа, а не животное. AnimateDiff v2
  на CPU снимал 8 кадров за 32 минуты и терял детали не хуже сервиса.
  Инфраструктура (образ с torch+diffusers, веса ~13 ГБ, скрипты) удалена
  из проекта, спрайты с тех пор не переделывались и не будут.

Анимация кодом в `scripts/main.gd`:

- **Заяц** — ростом с букву, движение — бодрые прыжки (фаза от
  пройденного пути, на земле — сплющивание), выпад-укус на букву,
  наклон при отрыжке, дыхание, еле заметная дрожь на подступах ежа
  (ёж не хищник; на самом уколе дрожи нет), моргание (две чёрточки
  поверх глаз; рамки глаз измерены по пикселям спрайта). В момент укола — шок на лице: глаза навыкате (белки +
  зрачки), рот раскрыт. Съедения нет: зайца укололи — и забавно,
  и не так обидно.
- **Ёж** — ростом с букву, походки нет (шар): частые мелкие
  покачивания + прыжки со сплющиванием в момент касания. Остановок нет
  вообще: на каждой строке у него лишние мили (заход слева из-за края,
  убег за конец), заяц их проскакивает быстро.
  Правило укола — ровно три случая. Обе координаты на общей сквозной
  оси (номер символа от начала уровня), D = touch + CONTACT_SLACK, где
  touch — честная геометрия спрайтов: половина видимого шара зайца (его
  спрайт центрируется на левом краю клетки буквы) + половина видимого
  шара ежа (альфа-бокс hedge.png — 145 px из 160).
  1) Одна строка: укол, как только заяц не правее ежа на D (ёж впереди на
     любом расстоянии — тоже укол: ёж всегда идёт, значит заяц оказался
     позади только прыжком назад через него).
  2) Строка ежа МЕНЬШЕ строки зайца: укола нет. Ёж ещё в своей строке
     (середина или post-туннель за её краем), до зайца ему целая строка
     миль. Ровно ради этого у каждой строки свой отступ ENEMY_PRE_CHARS:
     ёж входит в новую строку слева, и заяц в её начале успевает отойти —
     вход в строку сам по себе укола не даёт, ёж сначала подходит.
  3) Строка ежа БОЛЬШЕ строки зайца: укол сразу, расстояние не
     проверяется. При нормальной игре так быть не может — строку ежа он
     прошёл целиком (случай 2), значит прошёл её и заяц, а назад его
     отбросила только опечатка. Это ровно откат через угол строк: ось
     склеивает строки, поэтому там заяц часто ещё «впереди» по оси (ёж
     стоит в pre-туннеле своей строки), но это побег, а не стояние рядом.
  Кадр укола (детекция ДО обновления позиций спрайтов): позицию ежа не
  трогаем — он катится плавно, его координата в кадре касания и так
  верна. Заяц: встаёт ровно на дистанцию контакта, то есть ЛЕВЫЙ край
  шара зайца встаёт в ПРАВЫЙ край шара ежа (щели нет, «пары ежей
  целиком» тоже нет). Если заяц стоял — замирает как есть; если влетел
  в ёжа (прыжок назад через него или откат после ошибки) — выталкивается
  вперёд, но не дальше 2 символов, чтобы бросок не унёс его через
  пол-экрана. Через угол строк (случай 3) заяц переносится СТРОГО на
  строку ежа и встаёт ровно в касание, без капов: табло укола показывает
  честную картинку «заяц у ежа», а не то место, куда его отбросила
  ошибка.
  Пыль — из-под задней лапы (позади-ниже шара).

## Где лежит история

Полная переписка по проекту (включая все попытки генерации) — в сессии
opencode `ses_f1ce2079bffeisAQGDIN6P06aW`, «Рефакторинг детской игры
набора текста», 27.09–04.10.2026. Лежит в SQLite-базе opencode
`~/.local/share/opencode/opencode.db`, таблица `session_message`
(колонка `data` — JSON с блоками `text` и `tool`). Читается без
изменений базы:

```python
import json, os, sqlite3
sid = "ses_f1ce2079bffeisAQGDIN6P06aW"
db = os.path.expanduser("~/.local/share/opencode/opencode.db")
con = sqlite3.connect(f"file:{db}?mode=ro", uri=True)
for (data,) in con.execute("select data from session_message where session_id=? order by seq", (sid,)):
    msg = json.loads(data)
    if msg.get("text"):
        print(msg["text"])
    for b in msg.get("content") or []:
        if b.get("type") == "text":
            print(b["text"])
        elif b.get("type") == "tool":
            print((b.get("state") or {}).get("input", {}).get("command", ""))
```
