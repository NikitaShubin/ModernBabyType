# Откуда тексты обеих баз

Вся классика — общественное достояние (авторы умерли 70+ лет назад;
страницы Викитеки с такими текстами помечены `PD-old-70`, у az.lib.ru
только авторы-классики). Файлы хранят ОРИГИНАЛЫ как есть; правит только
парсер (`Texts.normalize_text`: тире → дефис, ёлочки и немецкие кавычки
долой, `…` → `...`, типографский апостроф → прямой, все пробелы →
обычные, ударения изданий снять) плюс чистка импорта (вики-разметка,
сноски `[...]`, заголовки `===`, метки сносок `*`, вики-отступы `:::`).
Слова не тронуты. Сказовая орфография («всє») сохранена как у автора;
предложения с буквами без клавиш фильтр пропускает целиком.
Покрытие (`_text_coverage`) проверяет ровно то, что набирает игра.
